# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **CMS-Mozambique** (`eGov-Global/CMS-MOZAMBIQUE`),
**please do not create a public GitHub issue or discussion.**

Use one of the two private channels:

1. **GitHub Private Advisory Form**
   Use the "Report a Vulnerability" button under the **Security** tab of this repository, or
   [file a private security advisory here](../../security/advisories/new).

2. **Email**
   Contact the eGov Foundation security team at `security@egovernments.org`.

## What to Include

- Description of the vulnerability and its impact
- Steps to reproduce the issue
- Affected component / directory and versions (if known)
- Logs, error traces, or proof-of-concept, if available

## Response SLAs

| Severity | First Response |
|---|---|
| Critical | 1 working day |
| High | 2 working days |
| Medium / Low | 4 working days |

## Responsible Disclosure

We will acknowledge your report within the SLA above, keep it confidential until a fix is
released, and credit you (with your consent) upon disclosure. Please give us reasonable time to
remediate before any public disclosure.
